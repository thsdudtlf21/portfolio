# Portfolio Site

## 파일 구조
- index.html : 사이트 기본 뼈대
- style.css : 전체 디자인 스타일
- app.js : 화면 전환, 목록/상세/Inform 페이지 출력
- config.js : 작품 데이터 수정 파일
- images : 작품 이미지 폴더
- CNAME : 개인 도메인 연결 시 사용

## 수정 방법
1. 작품명, 연도, 설명 수정: config.js 수정
2. 이미지 교체: images 폴더에 이미지 넣고 config.js의 image/detailImages 경로 수정
3. 색상, 여백, 폰트 크기 수정: style.css 수정

## 업로드 방법
GitHub Pages에 올릴 때는 이 폴더 안의 파일 전체를 그대로 업로드하면 됩니다.
